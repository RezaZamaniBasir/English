# Daily English PWA

یک PWA موبایل‌محور برای آموزش روزانه زبان انگلیسی با دو منبع:

- **English Grammar in Use, Fifth Edition — Raymond Murphy** (145 units)
- **1100 Words You Need to Know, Sixth Edition — Murray Bromberg & Melvin Gordon** (46 core weeks)

## ویژگی‌ها

- نصب روی Home Screen مانند اپ
- کار آفلاین پس از اولین بارگذاری
- مسیر روزانه حدود 30 تا 35 دقیقه: مرور فاصله‌دار + گرامر + لغت + خروجی نوشتاری
- یک Unit گرامر در هر جلسه؛ پس از Unit 145 مرور دوره‌ای تا پایان منبع لغت
- چهار روز 5 واژه جدید و روز پنجم مرور هفتگی برای هر هفته کتاب 1100 Words
- تلفظ واژه‌ها با Speech Synthesis مرورگر
- ذخیره پیشرفت، streak، واژه‌های سخت و یادداشت‌ها روی همان دستگاه
- Export / Import پیشرفت به JSON
- باز کردن مستقیم صفحه درست PDF منبع
- پیام پایان دوره بعد از تمام شدن هر دو منبع اصلی

## چرا PDFها داخل مخزن نیستند؟

برای جلوگیری از انتشار عمومی کتاب‌های دارای حق نشر، فایل PDF را داخل GitHub قرار ندهید. بعد از باز کردن اپ روی گوشی، از تب **تنظیمات** هر دو PDF را یک‌بار انتخاب کنید. فایل‌ها در IndexedDB همان مرورگر ذخیره می‌شوند و از آن به بعد دکمه‌های «صفحه آموزش»، «تمرین» و «صفحه کتاب» به PDF محلی شما وصل می‌شوند.

## انتشار با GitHub Pages

1. همه فایل‌های این پوشه را در ریشه یک repository قرار دهید.
2. در GitHub به **Settings → Pages** بروید.
3. **Deploy from a branch** را انتخاب کنید؛ branch را روی `main` و folder را روی `/ (root)` بگذارید.
4. آدرس GitHub Pages را باز کنید.
5. در تب **تنظیمات** دو PDF را وارد کنید.
6. روی Android از منوی Chrome گزینه **Install app / Add to Home screen** و روی iPhone از Safari گزینه **Share → Add to Home Screen** را بزنید.

## ساختار فایل‌ها

- `index.html` — پوسته اپ
- `styles.css` — رابط موبایل‌محور
- `app.js` — منطق پیشرفت، مرور، IndexedDB و PWA
- `curriculum.js` — نقشه Unitها و واژه‌های برنامه (بدون متن کامل کتاب‌ها)
- `manifest.webmanifest` — تنظیمات نصب PWA
- `sw.js` — cache آفلاین
- `icons/` — آیکون‌ها

## نکته درباره مسیر گرامر

خود کتاب Grammar in Use توصیه می‌کند Unitها را بر اساس نیاز انتخاب کنید و از Study Guide استفاده کنید. این اپ برای ساختن عادت روزانه، پیش‌روی ترتیبی را پیش‌فرض کرده، اما در تب گرامر می‌توانید Unit موردنظر را باز کنید یا نقطه ادامه برنامه را تغییر دهید.
